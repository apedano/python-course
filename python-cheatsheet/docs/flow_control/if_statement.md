# `If`

## Basic `if`

```python
age = 18

if age >= 18:
    print("You are an adult")
```
## `if / else`

```python
age = 16

if age >= 18:
    print("You are an adult")
else:
    print("You are a minor")
```

## `if / elif / else`

```python
score = 85

if score >= 90:
    print("Grade A")
elif score >= 75:
    print("Grade B")
else:
    print("Grade C")
```

## Boolean expressions

```python
x = 10

if x > 5 and x < 20:
    print("x is between 5 and 20")
```
