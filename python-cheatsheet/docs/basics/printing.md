## F-String (formatted strings) `f""`
In Python, we can use `f-strings` to insert a variable or an expression into a string.
```python
user = "Bob"
age = 42
print(f"{user} is {age} years old") 
```

```python
print(f"{2.675:.2f}")  # 2.67 (floating-point representation issue)
```
