## Float

## Boolean


## String

Subscription
```python
print("Hello"[0]) #H
```

Strings can be accessed as arrays
```python
print("Hello"[len("Hello")-1])

print("Hello"[-1]) #o
```

## Type check

```python
type(123) #<class 'int'>
type("a string") #<class 'str'>
type(3.1415) #<class 'float'>
type(True) #<class 'bool'>
```
